6 · Confidence tiers — shape + wording, never colour alone

Tier APROVEN MATCH
hierarchy-proofed via SNOMED ancestor closure, or exact concept in Medicus's own index · solid border · one-click Review & code
Tier BTEXT MATCH
exact description text, no hierarchy proof · solid border · Review & code with read-back
Tier CWEAK · SEARCH MANUALLY
combined fragments, riskiest · DASHED border, amber, positioned last · no code button exists on this tier — only "open Medicus search"

Distinction rides on border style (solid vs dashed), wording, position and colour together — survives colourblind mode because the triads swap wholesale.
