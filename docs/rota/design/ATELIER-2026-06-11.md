# Atelier Design Direction — 2026-06-11

The artist's call, synthesised from the critic pass. Execution is CSS-first; behaviour,
handlers, element ids and data-attributes are untouchable. Class names `.sev`/`.pill`/`.chip`
are KEPT (views reference them) — they are restyled onto shared token rules, not renamed.

## Tokens

- **Type scale (6 + display)**: 11 micro (roomtag) · 12 meta (.sub, th, badges) · 13 labels &
  small buttons · 14 body · 16 h2 · 20 h1 · 24 display (.kpi). Weights: 400 body, 600 medium,
  700 strong, 800 display/chips. Retire 9, 10, 15, 17, 21, 28px.
- **Radius scale (4)**: 6 chips/badges · 8 inputs & all buttons · 14 cards, rotawrap, menus,
  toast, bulkbar · 99 round pills. Print keeps 4.
- **Spacing utilities**: `.mt8 .mt10 .mt12 .mb8` plus `.card-section` (top-border group
  separator with 13px/700 heading) replace the worst inline styles.
- **Colour roles**: `--muted: #a8b4c8` (AA-safe), navfoot `#7a8599`, input background
  `rgba(255,255,255,.07)` with hover border state, `.empty` at `rgba(255,255,255,.30)`,
  brand gradient `#60a5fa → #818cf8`. `--accent2` is a gradient modifier ONLY — never a
  standalone foreground.

## Principles

1. **One accent.** Blue is the only interactive hue; indigo lives inside gradients on
   `button.primary` and nav-active, nowhere else.
2. **Glow is interaction.** Glows on primary buttons only. Remove: `.dot` box-shadow,
   `.sev.high` halo, `.kpi` text-shadows, nav-active inset ring.
3. **Elevation = blur + border.** The cell menu gets a `border-top: 1px solid
   rgba(255,255,255,.18)` highlight; shadows stop escalating.
4. **Every number has a label; every card has a heading.**
5. **Motion = entrance + urgency.** Keep fadeUp/popIn. Activate the vacancy stripe drift
   (`shimmer 3s linear infinite`, disabled under reduced-motion) as the one living element.

## Signature details

- Unified badge: `.sev` and `.pill` share one flat, legible badge treatment (12px/700,
  radius 99, tinted background + readable foreground, `print-color-adjust: exact`).
- The Rota toolbar reads as three bands: week navigation · segmented Staff/Rooms toggle ·
  a `<details>` Actions menu holding Generate / Auto-assign / Copy week / Assign rooms /
  Print, with Undo and Solve persistent.
- Vacancy shimmer: urgency you can see across the room.

## Explicit non-changes

The chip system and its per-session-type palette (the signature), the ambient gradient
background, glassmorphism depth model, nav width, the fadeUp cascade, and the icon question
(an in-repo SVG icon set is deferred: high effort, the type/spacing work pays more).
